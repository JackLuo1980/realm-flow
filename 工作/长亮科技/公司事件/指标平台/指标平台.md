## 客户主要需求：
1. 系统整合：整合现有报表系统、数据快查系统及自主用数工具（如图数据库、模型研发平台等）。
2. 统一用数门户：包含指标管理功能，抽象各类系统指标进行统一管理。
3. 数据产品运营中枢：实现数据产品（如报表、加工指标等）全生命周期管理（开发、上下线、迭代）及可视化展示、流程化管理。
4. 智能用数：结合大模型实现自然语言数据查询、报表生成等功能。
5. 数据沙箱：预加载原数据，支持业务人员通过Python、AI工具自主使用数据（具体实现方式待议）。

## 对标系统：
1. 招商银行“数智零售”，匹配点： 整合多系统，利用“数智小招”机器人实现智能播报与分析
   1. 观远数据 (Guanze)， 匹配点： 统一指标口径，覆盖数据产品从开发到运营的全生命周期
   2. 帆软 (FineBI/FineIndex)， 匹配点： 完善的报表运营中枢，提供强大的自助分析功能
   
   ## 推荐开源系统
   1. 统一用数门户 / 元数据目录（Catalog）
   * DataHub（LinkedIn 开源）：开源数据目录/元数据平台 
     * [datahub-project/datahub: The Metadata Platform for your Data and AI Stack](https://github.com/datahub-project/datahub?tab=readme-ov-file)
     * [https://sandbox.open-metadata.org/dataProduct](https://demo.datahub.com/)
   * OpenMetadata**：统一元数据平台（发现/治理/可观测等）
     * https://github.com/open-metadata/OpenMetadata?tab=readme-ov-file
     * https://sandbox.open-metadata.org/dataProduct
   2. 指标管理（Metrics Layer / 语义层）
   * dbt Semantic Layer：用统一语义层定义关键指标（由 MetricFlow 驱动）
   * MetricFlow（dbt-labs）：开源语义层/指标定义与编译
   * Apache Superset（语义层=Dataset + Metrics）：可在数据集层定义指标/派生列/元数据
   3. 数据产品运营中枢（全生命周期：开发/上下线/迭代/可视化/流程）
   * DataHub Data Products（Data Product as Code）* **OpenMetadata Data
   * Product 标准/实体：把表、看板、模型、API 等打包为“可发现、可治理”的数据产品
   * 工作流/流程编排（DataOps）：
     * **Apache Airflow**：以代码方式编排、调度、监控工作流
     * **Dagster**：偏“数据资产（asset）”理念的数据编排器
   4. 智能用数（NLQ / Text-to-SQL / 自动报表）
   * **Vanna（开源 Text-to-SQL）**：自然语言→SQL→结果，强调检索增强与权限能力
   * **LlamaIndex Text-to-SQL**：提供 Text-to-SQL 查询引擎与 schema 检索思路
   * **LangChain SQL QA**：提供创建 SQL 查询链等能力（工程化拼装方便）
   5. 图数据库、模型研发平台
   * **Kubeflow**：Kubernetes 上的 ML 平台工具集
   * **MLflow**：机器学习生命周期管理（实验、模型、部署等）
  
  
   ## 组合
   * **门户/资产目录**：DataHub 或 OpenMetadata
   * **指标语义层**：dbt Semantic Layer（MetricFlow）
   * **数据产品运营中枢**：DataHub/OpenMetadata 的 Data Product + Airflow/Dagster 流程（上线/下线/审批/回滚）
   * **智能用数**：Vanna 或 LlamaIndex/LangChain（Text-to-SQL）+ 权限/审计/SQL 沙箱
   * **数据沙箱**：JupyterHub（多租户隔离）+ Trino/湖仓/数仓只读视图 + 预置样例 Notebook
