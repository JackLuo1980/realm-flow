## 部署方式

### Docker 部署 (推荐)

```bash
# 1. 上传 docker-compose.yml 和镜像
scp docker-compose.yml root@91.233.10.38:/opt/realm-flow/

# 2. 启动服务
docker compose up -d
```

### 手动部署

```bash
# 1. 上传二进制和前端产物
scp -r bin/ root@91.233.10.38:/opt/realm-flow/
scp -r dist/ root@91.233.10.38:/opt/realm-flow/

# 2. 启动后端
./paneld -config config.json

# 3. 配置 Nginx 反向代理
```

## 注意事项
