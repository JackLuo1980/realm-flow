## FLVX UI 分析 (来自源码)

### 布局结构
- **AdminLayout**: 左侧边栏 + 顶部栏 + 主内容区
  - 侧边栏: 可折叠，Logo + 菜单 + 版本信息
  - 顶部栏: 汉堡菜单(移动端) + 用户下拉菜单(修改密码/退出)
  - 主内容: 带页面过渡动画 (Framer Motion)
- **H5Layout**: 移动端布局，底部导航
- **H5SimpleLayout**: 简化移动端布局

### 侧边栏菜单 (FLVX)
1. 仪表 (/dashboard)
2. 规则 (/forward)
3. 隧道 (/tunnel) - 管理员
4. 节点 (/node) - 管理员
5. 监控 (/monitor) - 需权限
6. 限速 (/limit) - 管理员
7. 用户 (/user) - 管理员
8. 分组 (/group) - 管理员
9. 共享 (/panel-sharing) - 管理员
10. 设置 (/config) - 管理员

### UI 组件体系
- **基础组件**: shadcn-bridge/heroui 桥接层（适配 shadcn 风格到 HeroUI 接口）
- **样式**: Tailwind CSS 4 + class-variance-authority
- **动画**: Framer Motion (侧边栏高亮跟随、页面过渡)
- **通知**: react-hot-toast + sonner
- **图表**: Recharts
- **拖拽**: @dnd-kit

### 登录页特点
- 居中卡片式登录
- Turnstile 验证码支持
- 默认密码强制修改
- 进入动画 (opacity + y 轴)

### 主题系统
- 深色/浅色模式
- 可扩展主题 (themes/ 目录)
- CSS 变量驱动
