# RealmFlow 系统架构

## 架构类型：精简高效架构 (对齐 FLVX)

> 与 FLVX 使用相同的架构模式：单体后端 + Gost 转发引擎

## 后端架构 (对齐 FLVX)

### 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| HTTP | Go 标准库 net/http | 不使用 Gin/Echo，轻量高效 |
| 路由 | http.NewServeMux | Go 1.22+ 增强路由 |
| WebSocket | gorilla/websocket | 实时通信 |
| ORM | GORM | 支持 SQLite + PostgreSQL |
| 认证 | JWT | 自实现，不引入第三方 |
| 加密 | AES + MD5 | 对齐 FLVX 加密方式 |

### 中间件链

```
请求 → CORS → RequestLog → JWT → Recover → Handler
```

## 前端架构 (对齐 FLVX)

### 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 框架 | React 18 | SPA |
| 构建 | Vite (rolldown-vite) | 极速构建 |
| 语言 | TypeScript | 类型安全 |
| UI | Radix UI + Tailwind CSS 4 | shadcn/ui 风格 |
| 图表 | Recharts | 流量图表 |
| 动画 | Framer Motion | 页面过渡 |
| 图标 | Lucide React | 现代图标 |
| Toast | Sonner | 通知提示 |
| 路由 | React Router DOM 6 | SPA 路由 |
| HTTP | Axios | API 请求 |
| 拖拽 | dnd-kit | 排序拖拽 |

### 页面路由

```
/           → 登录页
/dashboard  → 总览面板
/forward    → 转发管理
/tunnel     → 隧道管理
/node       → 节点管理
/user       → 用户管理
/group      → 分组管理
/monitor    → 监控
/limit      → 限速管理
/config     → 面板配置
/profile    → 个人资料
/settings   → 主题设置
/panel-sharing → 面板共享
/change-password → 修改密码
```

### 布局系统

- **AdminLayout**: 桌面端，侧边栏 + 内容区
- **H5Layout**: 移动端，底部导航
- **H5SimpleLayout**: 移动端简化布局
