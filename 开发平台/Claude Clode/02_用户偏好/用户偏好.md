## 服务器管理偏好

### 中国大陆服务器部署
- 对于中国大陆网络环境下的服务器，安装 agent 时使用离线部署方式：
  1. 本地下载二进制文件
  2. 使用 `scp` 上传到服务器
  3. 手动配置并启动服务 (systemd)
- 原因：避免依赖 GitHub 等外部源的超时问题

### 服务器信息存储
- 所有服务器配置信息集中在 `01_项目记忆/服务器清单.md`
- SSH 密码等敏感信息仅在需要时从用户处获取，不长期存储
