## 3. Komari 监控服务器

### 基本信息
- **IP**: 159.54.184.3
- **用途**: 节点监控服务
- **服务**: Komari Monitor
- **SSH 端口**: 22
- **SSH 用户**: root
- **SSH 密码**: lpsz800203

### 服务详情
- **容器名称**: komari
- **镜像**: ghcr.io/komari-monitor/komari:latest
- **数据库**: SQLite (`/home/docker/komari/komari.db`)

### 数据库规模
- `clients`: 175 条
- `records`: 52,813 条
- `records_long_term`: 367,852 条
- `ping_records`: 5,073,809 条
- `komari.db`: ~928MB

### 维护脚本
- **排序脚本**: `/root/komari_sort_by_name.sh`
- **日志**: `/root/komari-sort.log`

### 维护命令
```bash
# 手动执行排序
/root/komari_sort_by_name.sh

# 查看排序日志
tail -n 30 /root/komari-sort.log

# 查看前 30 个排序结果
sqlite3 -header -column /home/docker/komari/komari.db \
  "select name, weight from clients order by weight asc limit 30;"

# 查看数据库文件大小
ls -lh /home/docker/komari/komari.db*

# 查看 Komari 容器状态
docker ps --filter name=^/komari$
docker logs --tail 100 komari
```

### 定时任务
```cron
0 0 * * * /root/komari_sort_by_name.sh >> /root/komari-sort.log 2>&1
```

### 运行注意
- 若出现“删除提示成功但实际未删除”，先检查根分区是否满 (`df -h`)。
- 禁止恢复旧的高频 DB 备份任务（每 10 分钟备份到 `sort_backups`），避免再次打满磁盘。
- 新机器若 443 出站受限，按“RFC 中转 + SNI Forward + nftables OUTPUT DNAT”标准方案处理 agent 出站。
