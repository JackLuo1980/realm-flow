## 核心经验学习

### 1. 记忆管理原则
- 使用持久化项目记忆文件，而非仅依赖对话上下文
- 每次任务后总结经验，持续更新记忆
- 触发关键词："记住这条"、"更新记忆"、"把这个写进记忆"

### 2. 决策记录格式（Codex decision_log.md）
- **Background**: 背景/问题
- **Decision**: 决定内容
- **Why**: 为什么这样做
- **Follow-up**: 后续如何处理

### 3. 服务器运维经验
- **中国大陆部署**: 离线部署（本地下载 → scp 上传 → 手动配置）
- **Komari 出站受限**: RFC JP CO 双层中转 + SNI 转发 + nftables OUTPUT DNAT
- **验收标准**: 日志出现 "Basic info uploaded successfully" 和 "WebSocket connected"

### 4. Claude Code 配置排障
- **三步检查**: auth 冲突 → token 格式 → 模型映射
- **VS Code 插件**: 优先检查 `settings.json` 中的 `claudeCode` 配置
- **推荐插件**: superpowers、code-review、context7、claude-mem

### 5. 项目文档管理
- **主存储位置**: Obsidian
- **工作区文件**: 作为中间编辑区
- **最终文档**: 必须同步/保存到 Obsidian

### 6. 银行类 AI 项目方案
- **默认采用**: 知识库先行、规则约束、模型增强、人机协同、私有化部署、信创兼容
- **一期优先**: 推荐/判重/纠错
- **内嵌式增强**: 复用现有登录、菜单、权限与页面框架

1. **任务前检查**: 每次做任务前必须先查看之前的记录内容
2. **复杂任务使用计划模式**: 多种实现方案时使用计划模式
3. **TodoWrite 跟踪进度**: 多步骤任务使用 todo list 管理
