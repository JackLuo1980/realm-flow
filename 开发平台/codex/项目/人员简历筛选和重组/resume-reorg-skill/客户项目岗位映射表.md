# 客户项目岗位映射表

这个映射表用于把客户、项目、岗位信息、岗位内容统一成稳定口径，方便后续批量填简历、做去重和做差异化重组。

## 使用规则

- 先归一客户名称，再归一项目名称。
- 项目内容写“这个项目是做什么的”，不要写成个人职责。
- 岗位信息写“这个人是什么角色”，尽量标准化。
- 岗位内容写“这个角色通常负责什么”，要和该人的实际经历一致。
- 如果某条只能推断，标记为 `待确认`。

## 5. 建议的最终填法

后续填写时建议固定成下面的顺序：

1. 客户名称
2. 项目名称
3. 项目内容
4. 岗位信息
5. 岗位内容

例如：

```text
客户名称：平安银行
项目名称：平安银行智慧审计画像平台项目三期
项目内容：围绕智慧审计画像平台进行功能迭代、接口支持、数据处理、测试和上线支持
岗位信息：研发工程师
岗位内容：负责系统功能开发、接口联调、测试修复和上线支持
```

## 6. 待补充项

- 如果后续出现新客户，先补客户简称，再补项目家族。
- 如果同一客户下有多个项目，优先按“项目家族”归并，再按时间阶段拆分。
- 如果岗位内容差异很大，可以拆成“基础开发岗”“平台支持岗”“项目负责人岗”三类再细化。
