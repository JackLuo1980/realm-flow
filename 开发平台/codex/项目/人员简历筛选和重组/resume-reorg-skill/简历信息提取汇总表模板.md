# 简历信息提取汇总表模板

这个模板用于把每份简历里的关键信息统一抽出来，再汇总到一张总表里，方便后续做客户归一、项目去重和简历重组。

## 1. 表头建议

| 人员 | 客户名称 | 项目名称 | 项目内容 | 岗位信息 | 岗位内容 | 时间阶段 | 公司/机构 | 经验年限 | 经验等级 | 来源文件 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|

## 2. 字段说明

| 字段 | 说明 | 填写建议 |
|---|---|---|
| 人员 | 简历归属人姓名 | 直接填姓名 |
| 客户名称 | 统一后的客户名 | 优先填 `平安银行`、`国开行` 这种归一名称 |
| 项目名称 | 统一后的项目名 | 按合同、备案或简历主标题归一 |
| 项目内容 | 这个项目是做什么的 | 写项目范围，不写个人动作 |
| 岗位信息 | 人在这个项目中的角色 | 如 Java开发工程师、研发工程师、Tech Lead |
| 岗位内容 | 这个岗位通常负责什么 | 写职责范围，动词开头 |
| 时间阶段 | 项目时间 | 统一到 `YYYY.MM-YYYY.MM` 或 `YYYY.MM-至今` |
| 公司/机构 | 当时所在公司 | 按简历原文填写 |
| 经验年限 | 按毕业年限或客户规则换算 | 统一计算后填写 |
| 经验等级 | 根据年限换算后的等级 | 初级 / 中级 / 高级 |
| 来源文件 | 信息来源 | 填简历文件名或页码 |
| 备注 | 补充说明 | 冲突、待确认、可合并点等 |

## 3. 推荐填写规则

- 同一客户出现多次时，客户名称必须统一。
- 同一项目家族出现多次时，项目名称尽量统一到一条标准写法。
- 项目内容写“项目本身是什么”，不要写成“我做了什么”。
- 岗位内容写“这个岗位通常负责什么”，不要写成空泛标签。
- 如果项目内容和岗位内容都能从原文直接抽出，优先保留原文含义，不要过度改写。
- 如果只能推断，标记为 `待确认`。

## 5. 汇总方式

建议按下面顺序汇总：

1. 先按人员汇总
2. 再按客户归一
3. 再按项目家族归并
4. 再按岗位信息归类
5. 最后输出待确认事项

## 6. 后续用途

这张表可直接用于：

- 客户名称归一
- 项目内容抽取
- 岗位信息抽取
- 简历重组前的总览
- 去重表和共享项目池的生成
