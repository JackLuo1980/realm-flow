# 简历字段模板

这个模板用于批量抽取、去重和重组简历信息。建议先抽字段，再做去重，最后再重写简历。

## 1. 个人基础信息

| 字段 | 说明 | 示例 |
|---|---|---|
| 客户简称 | 用于统一项目归属，如国开行、平安银行 | 平安银行 |
| 客户全称 | 如合同或备案中有正式全称则填 | 平安银行股份有限公司 |
| 姓名 | 简历人员姓名 | 张三 |
| 性别 | 如有则填 | 男 |
| 出生年月 | 如有则填 | 1994-08 |
| 年龄 | 直接年龄 | 31 |
| 身份证号码 | 如需保留则填 | 44xxxxxxxxxxxxxxx |
| 毕业学校 | 最高学历学校 | XX大学 |
| 毕业时间 | 最高学历毕业时间 | 2019-06 |
| 第一学历 | 如需区分则填 | 大专 / 本科 |
| 专业 | 对应学历专业 | 软件工程 |
| 学位 | 学士 / 硕士等 | 本科 |
| 职称 | 如有 | 初级 / 中级 / 高级 |
| 职务 | 当前岗位名称 | Java开发工程师 |
| 现所在机构或部门 | 当前组织/部门 | 风险业务部 |
| 服务时间 | 当前机构任职时间 | 2023/08-至今 |
| 拟在本项目中岗位级别 | 目标项目级别 | 初级 / 中级 / 高级 |
| 资质认证 | 软考、PMP 等 | 软考中级认证 |
| 工作年限 | 按客户规则计算 | 9年 |
| 经验等级 | 按年限映射后的等级 | 高级 |

## 2. 经历摘要

| 字段 | 说明 | 示例 |
|---|---|---|
| 个人简介 | 一句话概括经验范围 | 从事Java开发多年，熟悉银行、风控、报表场景 |
| 主要经历 | 按时间倒序列出公司经历 | 2022.11-至今：长亮科技 |

建议格式：

```text
个人简介：从事Java相关开发多年，具备银行、风控、支付、报表等项目经验。
主要经历：
2022.11-至今：深圳市长亮科技股份有限公司
2021.01-2022.07：某科技公司
2017.05-2020.12：某软件公司
```

## 3. 项目经历主表

### 3.1 抽取字段

| 字段 | 说明 |
|---|---|
| 人员姓名 | 项目归属人 |
| 公司/机构 | 当时所在公司 |
| 客户名称 | 银行、企业、机构等 |
| 项目名称 | 项目全称 |
| 时间阶段 | 开始时间-结束时间 |
| 项目角色 | 开发工程师、Tech Lead、负责人等 |
| 项目内容 | 该项目核心业务方向 |

## 5. 简历重组表

### 5.1 重组字段

| 字段 | 说明 |
|---|---|
| 目标岗位级别 | 客户要求的岗位级别 |
| 需要补足项 | 缺少的项目、年份、职责 |
| 可复用项目 | 去重后的共享项目 |
| 可补充内容 | 经过确认的相似项目经验 |
| 差异化写法 | 与其他人不同的表达方式 |
| 风险提示 | 不能确认、不能扩写、需用户确认 |

### 5.2 推荐输出格式

| 人员 | 目标岗位级别 | 需补足项 | 可复用项目 | 可补充内容 | 差异化写法 | 风险提示 |
|---|---|---|---|---|---|---|
| 张三 | 中级开发工程师 | 缺少报表项目经验 | 智能决策平台 | 可补充报表核对、数据查询等 | 强调平台建设而非单点开发 | 需确认是否真实做过报表核对 |

## 6. 简历扩写模板

当某条项目经历过于简单时，可以按下面的维度扩写，但必须基于已有事实或用户确认：

- 业务范围
- 负责模块
- 开发流程
- 联调测试
- 上线支持
- 问题排查
- 性能优化
- 权限、报表、数据处理等配套工作

### 扩写前后示例

原句：

```text
负责系统模块开发。
```

可扩写为：

```text
负责核心模块开发、接口联调、功能测试及上线支持，配合业务人员完成需求落地，并跟进上线后的问题处理。
```

## 7. 统一命名规则

- 客户名统一到一个写法
- 项目名统一到一个写法
- 时间统一到 `YYYY.MM-YYYY.MM`
- 角色统一到少数标准项
- 职责描述统一用动词开头
- 同类项目尽量避免重复句式

## 8. 待确认信息

以下情况建议单独列出：

- 毕业年份缺失
- 时间冲突
- 项目名称写法不一致
- 关键职责无法从原文确认
- 需要补充但没有事实依据

## 9. 最终交付清单

建议最终交付这些表：

1. 个人基础信息表
2. 年限等级表
3. 项目去重表
4. 共享项目池
5. 每人简历重组表
6. 待确认事项表
7. 简历信息提取汇总表
