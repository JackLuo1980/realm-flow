## 项目定位
本项目定位为面向全行开发人员的“数据字典系统内嵌式贯标智能辅助建设项目”，核心能力包括：
- 智能取数
- 标准推荐
- 重复标准检测
- 智能纠错
- 知识库建设与持续运营
