# 兴业银行智能贯标项目页面原型说明

## 1. 说明
- 本文档作为《兴业银行智能贯标项目设计文档_v0.5.md》的页面原型附件
- 目标是集中说明页面职责、布局结构和关键交互，便于单独评审
- 页面层面的最终视觉稿仍可在后续评审中继续细化

## 2. 页面清单

### 2.1 智能取数首页
- 作为现有数据字典系统中的高频智能页签或增强查询页
- 核心目标：让用户在最短路径内完成查表、查字段、查标准和发起建标建议
- 页面结构：顶部导航、中心搜索区、快捷入口区、结果展示区、右侧辅助区
- 关键交互：自然语言输入、示例提示、历史查询、结果卡片、复制字段、收藏、发起建标

### 2.2 智能取数结果详情页
- 用于承接字典查询后的深度查看
- 核心目标：帮助开发人员确认是否可直接使用，并保留返回字典详情的上下文
- 页面结构：顶部摘要区、左侧主结果区、中部依据区、右侧操作区、底部反馈区
- 关键交互：复制字段路径、查看相似字段、标记有用/无用、跳转新增建标页

### 2.3 标准推荐与判重页
- 作为标准录入或维护页面的增强面板
- 核心目标：在新增或变更标准时获取推荐结果和重复风险提示
- 页面结构：左侧录入区、中间结果区、右侧依据区
- 关键交互：采纳推荐、部分采纳、继续新建、标记误报、提交审核

### 2.4 智能纠错与建标页
- 用于标准草案修订与未命中场景下的建标建议承接
- 核心目标：把智能取数无结果或标准草案错误修正为可审核的建标内容
- 页面结构：顶部步骤条、左侧草案编辑区、右侧检查区、底部对比区
- 关键交互：高亮错误字段、查看规则命中原因、一键采纳建议、再次校验

### 2.5 知识库运营页
- 面向标准管理员
- 核心目标：集中管理知识导入、规则维护和知识质量巡检
- 页面结构：顶部筛选区、左侧导航区、中间列表区、右侧详情区
- 关键交互：导入字典和文档、重建索引、维护术语同义词、配置规则启停

### 2.6 审核工作台
- 面向标准管理员和架构人员
- 核心目标：承接推荐、判重、纠错和建标建议后的人工确认
- 页面结构：顶部统计区、左侧任务列表、中部内容区、右侧操作区
- 关键交互：逐条审核、批量处理低风险项、填写驳回原因、沉淀新规则

### 2.7 运营看板页
- 面向科技管理人员和领导汇报场景
- 核心目标：展示项目价值、推广效果和治理进展
- 页面结构：顶部核心指标区、中部分析图区、底部明细区
- 关键交互：近 30 天与累计口径切换、导出截图或报表、穿透查看未贯标对象

## 3. 导航与权限
- 一级导航建议沿用数据字典现有导航
- 在相关菜单下增加智能取数、标准推荐、纠错建标、知识运营、审核工作台、运营看板
- 开发人员默认看到字典查询、智能取数、历史记录、个人收藏
- 标准管理员默认看到推荐、纠错、知识运营、审核工作台
- 科技管理人员默认看到运营看板和关键指标概览

## 4. 评审建议

- 若要评审最终视觉风格，可结合 13.9 的高保真示意图一起看
