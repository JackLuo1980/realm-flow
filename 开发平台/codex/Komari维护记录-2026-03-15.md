## 3. 节点排序脚本

### 3.1 脚本路径

- `/root/komari_sort_by_name.sh`

### 3.2 当前脚本职责

- 备份当前数据库到：`/home/docker/komari/sort_backups`
- 若存在 WAL 文件，也一并备份
- 按以下规则重排 `clients.weight`
  - `A-Z / a-z / 0-9` 开头的名称优先
  - 非英文数字开头的名称放后面
  - 同组内按 `name COLLATE NOCASE ASC, uuid ASC`
- 执行 `PRAGMA wal_checkpoint(TRUNCATE);`
- 自动清理 14 天前的旧备份

### 3.3 当前脚本内容

```bash
#!/usr/bin/env bash
set -euo pipefail

DB="/home/docker/komari/komari.db"
BACKUP_DIR="/home/docker/komari/sort_backups"
LOG_PREFIX="[komari-sort]"

mkdir -p "$BACKUP_DIR"

if [ ! -f "$DB" ]; then
  echo "$LOG_PREFIX database not found: $DB" >&2
  exit 1
fi

TS="$(date +%F_%H%M%S)"
BACKUP_DB="$BACKUP_DIR/komari.db.${TS}.bak"
BACKUP_WAL="$BACKUP_DIR/komari.db-wal.${TS}.bak"

cp "$DB" "$BACKUP_DB"
if [ -f "${DB}-wal" ]; then
  cp "${DB}-wal" "$BACKUP_WAL" || true
fi

sqlite3 "$DB" <<SQL
BEGIN;
WITH ordered AS (
  SELECT uuid,
         ROW_NUMBER() OVER (
           ORDER BY
             CASE
               WHEN TRIM(COALESCE(name, '')) GLOB '[A-Za-z0-9]*' THEN 0
               ELSE 1
             END ASC,
             name COLLATE NOCASE ASC,
             uuid ASC
         ) - 1 AS new_weight
  FROM clients
)
UPDATE clients
SET weight = (
  SELECT new_weight
  FROM ordered
  WHERE ordered.uuid = clients.uuid
);
COMMIT;
PRAGMA wal_checkpoint(TRUNCATE);
SQL

find "$BACKUP_DIR" -type f -mtime +14 -delete

echo "$LOG_PREFIX completed at $(date +%F_%T)"
sqlite3 -header -column "$DB" "select name, weight from clients order by weight asc limit 10;"
```

## 6. 排序规则说明

### 6.1 当前规则

按以下优先级排序：

1. 英文/数字开头名称
2. 中文或其他字符开头名称
3. 同类名称内按字母顺序
4. 名称完全相同时按 `uuid`

## 7. 后续如果要改排序

### 7.1 改为纯名称排序（不区分中文）

修改脚本 SQL 里的：

```sql
ORDER BY
  CASE
    WHEN TRIM(COALESCE(name, '')) GLOB '[A-Za-z0-9]*' THEN 0
    ELSE 1
  END ASC,
  name COLLATE NOCASE ASC,
  uuid ASC
```

改成：

```sql
ORDER BY name COLLATE NOCASE ASC, uuid ASC
```

### 7.2 改为中文按拼音排序

- SQLite 默认不支持拼音排序
- 如果后续要做拼音顺序，建议改成：
  - 用外部脚本先生成排序键
  - 或将排序逻辑放到前端/后端程序里处理
