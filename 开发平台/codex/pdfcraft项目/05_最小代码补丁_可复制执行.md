## 改动1：`src/lib/pdf/processors/ocr.ts`

把 `initializeTesseract` 改为“本地优先 + CDN 回退”：

```ts
private async initializeTesseract(languages: OCRLanguage[]): Promise<void> {
  const Tesseract = await import('tesseract.js');
  const langString = languages.join('+');

  const localOptions = {
    workerPath: '/tesseract/worker.min.js',
    corePath: '/tesseract-core',
    langPath: '/tessdata',
  };

  const cdnOptions = {
    workerPath: 'https://cdn.jsdelivr.net/npm/tesseract.js@6.0.1/dist/worker.min.js',
    corePath: 'https://cdn.jsdelivr.net/npm/tesseract.js-core@v6.0.0',
    langPath: 'https://tessdata.projectnaptha.com/4.0.0',
  };

  try {
    this.tesseractWorker = await Tesseract.createWorker(langString, 1, localOptions) as unknown as TesseractWorker;
  } catch (e1) {
    console.warn('[OCR] local tesseract init failed, fallback to CDN:', e1);
    this.tesseractWorker = await Tesseract.createWorker(langString, 1, cdnOptions) as unknown as TesseractWorker;
  }
}
```

说明：
- 只改 1 个函数。
- 上游升级时，冲突点极小。

## 改动2：`src/components/tools/ocr/OCRPDFTool.tsx`

把错误展示从仅 message 改为“message + details”：

```ts
const detail = output.error?.details ? `\n${output.error.details}` : '';
setError(`${output.error?.message || 'Failed to perform OCR on PDF.'}${detail}`);
```

说明：
- 便于快速判定是资源下载问题还是 PDF 本体问题。
