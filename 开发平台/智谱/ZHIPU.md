# 智谱AI助手使用指南

> 本文件记录智谱AI助手的工作偏好和习惯

## 通信风格

- 简洁直接，不说废话
- 使用中文交流
- 避免使用 emoji（除非用户明确要求）
- 代码引用使用 markdown 链接格式: `[filename.ts](path/to/file.ts#L42)`

## 工作流程偏好

1. **任务前检查**: 每次做任务前必须先查看之前的记录内容
2. **复杂任务使用计划模式**: 当任务复杂或有多种实现方案时，使用计划模式
3. **使用 TodoWrite 跟踪进度**: 多步骤任务使用 todo list 管理
4. **优先使用专用工具**: 读取用 Read，搜索用 Grep，编辑用 Edit
5. **避免过度工程**: 只做必要的改动，不添加多余功能

## 记忆管理

- 所有工作文件都保存在Obsidian文件夹中
- 每次完成重要任务后，更新记忆文件
- 触发记忆更新的关键词:
  - "记住这条"
  - "更新记忆"
  - "把这个写进记忆"
